# Movie Hub

**Description:**  
A full-stack web application to browse and discover movies in real-time using The Movie DB API.

---

##  Features
- Browse trending movies with details like title, rating, release date.  
- Search movies by name and filter by genre.  
- Responsive UI for seamless experience on desktop and mobile.

---

##  Tech Stack
- Frontend: React, CSS  
- Backend: Node.js, Express (if used)  
- API: The Movie DB API
